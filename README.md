# Virtual Physiotherapy Guider for Knee Osteoarthritis

Final year undergraduate research thesis (2023–2024), exploring computer vision 
and machine learning methods to guide physiotherapy exercises for 
knee osteoarthritis patients.

## Overview
- Developed a real-time computer vision tool to track and assess 
  patient movement during physiotherapy exercises.
- Applied machine learning models to evaluate movement accuracy 
  and provide corrective feedback.
